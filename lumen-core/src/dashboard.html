Quick Setup

Point your LLM client at one of the URLs above (sets ANTHROPIC_BASE_URL, OPENAI_BASE_URL, etc).

Launch Your Client

Paste into a terminal. Env vars stay set for the shell session — re-export in any new terminal. Relay-mode clients (Claude Code, OpenCode) skip CA trust entirely; proxy-mode clients (Cursor, Claude Desktop) need the CA installed first (see TLS Certificate below).

Monitored Hosts

Hosts whose HTTPS traffic Lumen will intercept and parse for token usage.

Relay Routes

Plain-HTTP relay endpoints — clients send to http://localhost:9090/<prefix> and the daemon re-originates HTTPS to the upstream. No CA trust required.

TLS Certificate (for HTTPS proxy mode)

Download ca.pem 
sudo security add-trusted-cert -d -r trustRoot \
  -k /Library/Keychains/System.keychain \
  ~/Downloads/lumen-ca.pem
Or use the Lumen menu bar app: Settings → Certificate → Trust CA.
# Debian / Ubuntu
sudo cp ~/Downloads/lumen-ca.pem /usr/local/share/ca-certificates/lumen-ca.crt
sudo update-ca-certificates

# Fedora / RHEL
sudo cp ~/Downloads/lumen-ca.pem /etc/pki/ca-trust/source/anchors/
sudo update-ca-trust
# PowerShell (run as Administrator):
Import-Certificate -FilePath "$env:USERPROFILE\Downloads\lumen-ca.pem" `
  -CertStoreLocation Cert:\LocalMachine\Root
Or double-click lumen-ca.pem → Install Certificate → Local Machine → Trusted Root Certification Authorities.
Only needed for proxy-mode clients (Claude Desktop, Cursor). Relay-mode clients (Claude Code, OpenCode) don't require CA trust.
